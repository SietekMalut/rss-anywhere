    Pratinjau isi feed
      Riwayat di browser ini

      Cara pakai

      1. Tempel URL halaman (beranda, kategori, atau blog) lalu klik Buat Feed.
      2. Salin link feed permanen yang muncul.
      3. Tempel ke aplikasi pembaca RSS apa pun: Feedly, Inoreader, FreshRSS, NetNewsWire, Reeder, Thunderbird, dsb.
      4. Link itu bisa dibuka dari perangkat mana pun — server yang menjalankannya bukan komputer Anda.

      Parameter endpoint

      ParameterNilaiKeterangan
      urlwajibHalaman atau feed yang mau diubah.
      limit1–100 (20)Jumlah item. Diabaikan untuk feed asli (dipassthrough).
      ttl60–86400 (900)Berapa detik hasil disimpan di cache edge.
      filterteksHanya ambil item yang URL/judulnya mengandung teks ini.
      modeauto / html / feedhtml = paksa ekstraksi, feed = wajib feed asli.
      nocache1Lewati cache (berguna saat menyetel selector).

      Bagaimana ia bekerja

      Server mengambil halaman dari sisi server (jadi tidak kena batasan CORS), lalu berurutan: (1) mendeteksi feed asli lewat <link rel="alternate">, (2) mencoba path umum seperti /feed, /rss.xml, /atom.xml, (3) mengekstrak daftar artikel dari HTML (heading, anchor, tanggal, JSON-LD), (4) memakai sitemap.xml sebagai jalan terakhir. Hasilnya disimpan di cache edge supaya cepat dan hemat.

      RSS Anywhere · dibuat untuk dipakai, bukan untuk di-install. Tidak menyimpan data Anda. Cache hanya berisi HTML publik yang sedang diambil.
