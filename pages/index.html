RSS Anywhere

Link feed RSS publik dari website mana pun. Dibuat oleh GitHub Actions, disajikan GitHub Pages — komputer Anda tidak perlu menyala.

Link dibuat otomatis dalam ±1 menit lewat GitHub Issue. Setelah jadi, linknya permanen dan diperbarui tiap 30 menit.

    Cara pakai

    1. Tempel URL halaman (beranda, kategori, atau blog) lalu klik Buat link feed.
    2. GitHub terbuka dengan issue yang sudah terisi — klik Submit new issue.
    3. Tunggu ±1 menit, lalu salin link feed dari daftar di halaman ini (atau dari komentar di issue).
    4. Tempel link ke pembaca RSS: Feedly, Inoreader, FreshRSS, NetNewsWire, Reeder, Thunderbird, dsb.

    Bagaimana ia bekerja

    GitHub Actions mengambil halaman dari sisi server, mendeteksi feed asli (<link rel="alternate">), lalu path umum (/feed, /rss.xml, /atom.xml). Kalau tidak ada, daftar artikel diekstrak dari HTML, dan sitemap.xml dipakai sebagai jalan terakhir. Hasilnya disimpan sebagai file XML statis di GitHub Pages dan diperbarui tiap 30 menit.

    Batasan

    • Menambah feed baru butuh login GitHub (hanya pemilik repositori yang diproses).
    • Isi feed diperbarui tiap 30 menit, bukan real-time.
    • Konten di balik login atau yang dirender JavaScript tidak bisa diambil.
    • Situs dengan proteksi bot bisa menolak (403/405/429). Feed lama tetap tersedia.
